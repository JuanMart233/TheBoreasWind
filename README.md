#Objetivos de la aplicación:

Esta aplicación tendrá como propósito reunir información importante de manera clara, organizada y fácil de entender, permitiendo que los usuarios puedan resolver dudas y aprender más fácilmente sobre el funcionamiento del videojuego Genshin Impact.
1. Ayuda a los nuevos jugadores a entender el juego
2. Guía rapidamente a los jugadores antiguos
3. Presenta la información simplificada
4. Muestra la información en base a tu nivel de experiencia en el juego

#Descripción del proyecto

La aplicación buscará ofrecer una interfaz sencilla y accesible para evitar la saturación de información, proporcionando herramientas útiles como recomendaciones básicas, explicaciones simples y apoyo para mejorar la experiencia de juego.

#Actividad N.4 CRUD Completo de una de las tablas 

Cambios para la aplicación:

1. Se implementó una pantalla en la que puedes escoger tu nivel de experiencia en el juego.
2. Se creó un quiz de diez preguntas en el que tendrás que comprobar si tienes el nivel de experiencia que dices tener, si completas el quiz correctamente, podrás acceder al nivel experto so contestas 8 o más preguntas correctamente.
3. El menú principal ahora contiene un apartado en el que puedes personalizar tu perfil
4. Split donde aparece tu perfil y las siguientes opciones:
5. Cambio de cuenta
6. Cerrar sesión

#Apartados de pestaña

   1. Pestaña principal
   2. Pestaña de guías
   3. Pestaña de perfil
   4. Editar perfil
   5. Cambiar nombre
   6. Cambio de contraseña
   7. Cambiar tu foto de perfil por medio de URL
