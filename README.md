#Actividad N.4 CRUD Completo de una de las tablas 

Cambios de la aplicación para la aplicación:

1. Se implementó una pantalla en la que puedes escoger tu nivel de experiencia en el juego.
2. Se creó un quiz de diez preguntas en el que tendrás que comprobar si tienes el nivel de experiencia que dices tener, si completas el quiz correctamente, podrás acceder al nivel experto so contestas 8 o más preguntas correctamente.
3. El menú principal ahora contiene un apartado en el que puedes:
   *Split donde aparece tu perfil y las siguientes opciones:
   *Cambio de cuenta
   *Cerrar sesión
